# Teoría de Grupos para la Mecánica Cuántica

Certámenes del curso organizados para incorporarlos al repositorio de pregrado.

## Contenido

- `certamen-1/` — contiene `certamen-1.pdf` y `certamen-1.tex`.
- `certamen-2/` — contiene `certamen-2.pdf` y `certamen-2.tex`.

El PDF del Certamen 1 está fechado el 28 de julio de 2026 y tiene 5 páginas. El PDF del Certamen 2 está fechado el 10 de julio de 2026 y tiene 7 páginas.

## Verificación de versiones

Para el Certamen 1 se compararon las copias `J.R.-EP1-R4-TG.pdf`, `J.R.-EP1-R3-TG.pdf` y `certamen_TG_revision_3_Crisostomo.pdf`, además de versiones anteriores. Se eligió la revisión R4 por ser la más reciente y por conservar la entrega completa.

Para el Certamen 2 se localizó `J.R.-EP2-TG.pdf` como la copia final disponible. En OneDrive aparecieron clases, guías y un apunte, pero no copias de los certámenes; por eso esta carpeta contiene únicamente los dos certámenes encontrados.

No se localizaron las fuentes LaTeX originales de estos PDFs entre los archivos disponibles. Los archivos `certamen-1.tex` y `certamen-2.tex` son transcripciones LaTeX reconstruidas desde los PDFs, identificadas como tales en sus comentarios iniciales. El apunte transcrito de Teoría de Grupos se excluyó deliberadamente: no corresponde al contenido solicitado para esta carpeta.
